# Moovie Project – Meeting Notes & Documentation

## Overview
- **Project Theme:** Moovie + theme switching based on search (horror, Christmas, fantasy)
- **Team Size:** 4 FullStack developers
- **Goal:** Grade target 5
- **Core Tech Stack:**  
  - PostgreSQL  
  - Node.js  
  - Docker  
  - Postman (Swagger)  
  - DBeaver  
  - Visual Studio Code  
  - JavaScript / TypeScript (TBD)

## Workflow
- Work asynchronously (not all coding at the same time)
- Task division agreed twice per week (Mon & Thu, exceptions as needed)
- Daily Scrum updates via Discord (what you plan to do / what you did)
- Documentation done collaboratively and updated regularly (Swagger++)

## Roles (informal, evolving)
- Scrum Master  
- Frontend  
- Backend  
- Database  

## Optional Features
- “Now in cinemas” (Finnkino integration)  
- Group page customization (bonus for active yearly user)  
- Review moderation / censorship if needed
